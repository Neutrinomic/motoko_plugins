Reviewed the complete public wrapper and its delta, plus the unchanged native generator, reference evaluator, schema, and registration. The production wrapper is 17 lines shorter. Public signatures, ABI 1, stable node layout, cached metadata, and native update/set algorithms remain unchanged.

- Structural sharing and opaque payload references remain intact. Native update flags still distinguish unchanged roots, value-only replacement, and structural changes; old-value results and nested optional values retain their existing meaning. Callback arities, ascending traversal order, descending foldRight order, and conflict argument order are preserved.
- Every changed private Nat32 depth starts at zero. An increment follows a successful `depth <= 128` guard, so its result is at most 129; the next guard traps before another increment. Wrapping is therefore unreachable. Recursive guards still run before matching null children: the new tests accept 128-node folds and reject the depth-129 empty child in both directions.
- Lazy replay maintains a count of entries skipped in its chosen traversal direction, a stack of later ancestors, and the next pending subtree. Forward/reverse bounds, empty intervals, repeated exhaustion, and independent replay are sound. The stack and snapshot retain managed references across GC. Descent checks now happen during advancement and can reject forged trees at a different time or path; this is documented. Explicit `assertValid` remains the full invariant check.
- Merge tails preserve the original stable comparison order. Duplicate compaction consequently retains the last comparator-equal key object and value, without copying payloads.
