# Ordered Set benchmark results

Verified [raw evidence](../results/set-comparison/README.md) from plugin implementation commit `7f2e675549ad2296e4be4f6b404107c2d5957f63`. See [reproduction and boundaries](README.md). Cells round per-operation averages to two decimal places; JSON retains exact totals.

Each cell is median IC instructions / cumulative allocated bytes per operation. Point operations average 32 probes; construction, iteration, union, and intersection measure one complete operation. Inputs are freshly rebuilt outside the measured block, except construction itself. Validation follows measurement. All keys are Nat; generic uses a comparator callback, native uses the Nat helper.

162 cases × 3 independent trials. Instruction and allocation counts identical across trials: True.
