# Ed25519 public module coverage

Loads only `ed25519`, with `--sanity-checks --force-gc`.

| Method | Independent expectation / regression |
| --- | --- |
| `test_rfc8032_all_pure_vectors` | All five RFC8032 §7.1 exact key/signature answers; changed message fails |
| `test_openssl_boundary_vectors` | Node/OpenSSL exact answers for ten lengths from 0 through 4096 bytes |
| `test_seed_lengths_and_error_recovery` | Invalid lengths; legal zero/all-ones seeds; seeded keypair; error ordering and subsequent success |
| `test_canonical_points_small_order_and_scalar_ranges` | Identity, order-two/four points, negative zero, y>=p, S>=L, legal S=0 mismatch |
| `test_aliases_input_immutability_and_pure_mode` | Intrinsic aliases, ordinary function wrapper, retained blobs, unchanged inputs, pure Ed25519 over digest bytes |
| `test_retained_outputs_across_forced_gc` | Retained signature/keypair and aliases across await boundaries; >64MiB discarded pressure and explicit reclaimed-byte assertion |

[`../ed25519/Suite.mo`](../../ed25519/Suite.mo) also runs through the portable
interpreter and compiled Wasm from `tests/run/crypto-ed25519.mo`. Exact vectors
are generated from the archived independent JSON fixtures; runtime tests also
reject every Dalek eight-torsion point and noncanonical y=p..p+18 with both signs.
See the plugin README for the deliberately strict uncofactored acceptance policy.
