# SHA512 test coverage

Public API: `digest`, `digest384`, and the `Digest`/`Digest384` classes with
`write`, non-destructive `sum`, and `reset`.

| Test | Coverage |
| --- | --- |
| `test_nist_known_answers` | SHA-512 and SHA-384 empty, abc and 112-byte standard messages; independent fixed answers. |
| `test_padding_boundaries_and_stream_partitions` | Binary patterns at 0, 1, 63, 64, 111–113, 127–129, 239–240, 255–257, 1024, 65537 bytes; chunk sizes 7, 111, 128, 129, 4096; repeated sum, empty update, reset and immutable input. |
| `test_nondestructive_sum_and_independent_streams` | Interleaved streams, continuation after sum, preserved earlier outputs, reset isolation, both modes. |
| `test_aliases_callbacks_and_evaluation_order` | Inferred alias, object field, ordinary callback and exactly-once callee/argument evaluation. |
| `test_million_byte_vectors` | SHA-512 and SHA-384 standard million-a known answers. |

Binary byte i = `(i * 131 + 17) % 256`. Committed answers were generated by
Python's hashlib/OpenSSL, independently of both plugin implementations. Native
tests additionally cover invalid state encodings, byte-length overflow and
128-bit carry, unaligned pointers, output guards and input preservation.
Internal Prim fixtures ensure malformed states return `null`, and source/IR
interpreter semantics are exercised by the standard plugin/package run suite.
